# 对手策略与失败经验

> 本文的历史跨难度结论需重新验证，参见 [0.1.1 修复说明](difficulty-fix.md)。

本页说明选定打法和训练启发；不是保证获胜的攻略。适用范围仅为 MAME 0.288
的 `sf2` World 910522。动画数值和距离阈值不能直接移用于其他 SFII 版本。
实验流程见[训练方法](training-method.md)，阶段背景见[训练历史](training-history.md)。

## 几个推动改进的例子

### Vega：停表不是结算完成

历史败局中 Ken 在计时首次归零时领先，旧程序松防后仍被击倒。配对轨迹在
归零前相同，首次差异就是松键或继续防守。改进保留未决窗口的普通防守，
直到 KO、胜点或结果姿势等状态明确，再由 Core 完成成熟结算。

后续低空下降优化只针对已识别的动画与原选招窗口等待；全面后退或全面改用
轻升龙曾产生回归。不能把局部等待的成功解释成 Vega 的投技都可防住。

### Sagat：找到真正的危险窗口

早期真实败局的损血集中在跳入下降、空中重脚已经收招时。提高跳入距离下限
以及特定低血扫腿窗口先防守，在当时配对条件中改善了结果；更大距离和更快
升龙也有失败，并非数值越大或输入越快越好。

后续最高难度训练继续演变，V4 使用表中的 `c19_sagat_low_wait`。早期
`sagat_far_sweepguard` 的阈值说明是历史经验，不能当作当前完整策略。

### Blanka 与 Balrog：避免在收招阶段被追击

Blanka 的陌生招式需要结合动画与画面识别，不能凭一次掉血就猜成电击；
历史复盘区分过横向滚击、波动拳恢复和扫腿恢复。远距出波与收窄扫腿范围
降低了一些风险，但远距离不保证安全。低血领先等待还可能把 KO 胜变成
时间胜、减少余血，因此必须同时检查整场与小局回归。

Balrog 的失败中，Ken 扫腿尚未收招，对手已经落到近处，再输入升龙也来不及。
收窄扫腿范围比只替换对空拳强度更有针对性。分析应回到决定扫腿的那一帧，
不能只看受击时双方已经贴近的位置。

### Bison：窄条件投技与被淘汰的泛化

历史试过轻/中/重升龙、下降防守、出波距离和输入时序等候选，训练有改善
仍可能在新尾关开局失败。V3 最终采用的地面投技条件很窄：原选择为 DP、
对手 `y == 40` 且水平距离 `< 48` 时，发送普通方向加 HP，再后退。

较宽的近身投条件不是同一模式。精确条件通过也不能推广成所有低空对手都
可投；不要把候选注册名当成选用证据。停表后投技 KO 还需要 Core 正确认出
成熟结算，策略改进与判胜修复须分别说明。

### Dhalsim：最终 V4 的局部改动

V4 委托既有确认防守模式，只在原选择为“远距可见攻击起跳”、距离至少 240，
且当前动画属于 `303076/303100/303124/303148` 时改为 2 帧蹲防。
较早的中距动画序列防守候选没有推广。

这项改动也可能放弃原本能打中的进攻，或把 KO 变为较小优势的时间胜。
它改善了覆盖到的训练条件，不证明其他距离和动画都安全。最终同期的
Blanka 快 MP 候选因缺少有效靶窗口证据没有选入 V4。

## 跨角色通用教训

Ryu、Zangief 和 Guile 的出波输入调整说明：改变按键持续时间是在改变交手
时序，没有改变游戏自身招式帧数据。Guile 两帧候选曾失败，三帧才被采用，
不能把一个对手有效的宏直接推广到所有人。

Honda 和 Chun-Li 曾受益于空中轻升龙，但后续仍需要针对下降或停表窗口
修补。高难度的成功不能替代低难度回归；对手在路线中的出场位置也要记录。

判胜不能只看 HP：HP 为 0 仍可能存活，timer 为 0 后也可能有攻击结算。
Core 结合原生胜点、至少 360 帧等待、成熟姿势和锁定时间血量。遇到未知姿势
保留 invalid，用已核实状态做窄修复和反例测试，不能宽松判赢或回填旧记录。
