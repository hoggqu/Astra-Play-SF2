# 从试玩到冻结 V4：训练演进

本页保留训练思路、关键决策和失败教训，不分发历史运行数据。内容由原本机
Skill 及 Boss06、Vega07、Sagat08、Hardest/Cross14、Coin17/19/22 等阶段说明
整理而来；这些名称是历史阶段标识，不是发行版可运行的命令或目录。
新读者无需取得旧工作区即可阅读本文和[训练方法](training-method.md)。

原始日志、截图、ROM、存档、逐帧数据、逐次胜率表与废弃执行器都未随本文加入。
这里对历史结果的描述属于项目回顾，不能仅凭本页重新审计那些比赛。
最终成绩摘要与冻结身份见[验证记录](validation.md)，时间和 Token 统计沿用
[README 的既有快照](../README.zh-CN.md#时间与-token-消耗)，不在这里扩充历史台账。

## 1. 从交互式试玩到可复用脚本

最初目标是在 Mac 上找到 MAME，然后用 Ken 尽可能多地击败对手。训练逐渐从
观察画面、尝试招式，发展为 Lua 读取当前双方位置、血量和动作，发送普通
方向与拳脚输入。Python 负责启动和编排，经验写入 Skill 供 Agent 接手。

这不是视觉端到端模型，也不是学习游戏未来决策。后来固定的程序可以脱离
Agent 运行；图片用于检查画面和结果，当前状态与自动判胜主要来自 RAM。

## 2. 开局存档训练与逐小局统计

完整路线失败后从头再打，训练后期对手的成本很高。于是为高败率对手准备
完整 R1 存档，反复比较不同打法，并开始统计每一小局。重点从 Sagat、Vega、
Bison 扩展到 Ryu、Honda 等角色。

很快发现整场胜率与小局胜率可能朝不同方向变化：候选虽然更常赢下 2:1，
却可能丢掉更多小局。另一个问题是相同开局反复成功，看起来很稳定，面对
新路线仍会失败。因此开始保留原策略、做配对实验，并使用预留开局复测。

## 3. 收紧正式规则，自动执行完整比赛

用户明确要求正式通关零读档、零 continue，并进一步禁止在整场对手战中暂停
或临时改打法；训练仍允许读档、暂停和优化。早期含暂停的连胜留作旧规则
成绩，不追认为新规则通关。

Lua 因此承担从 R1 到整场成熟结算的连续执行，Python 只编排完整比赛与过场。
批量训练预先固定计划，批次结束后集中复盘。速度在开赛前确定，判胜自动化，
减少每局开始和结束时等待 Agent 的时间。

## 4. Boss 训练推动诊断与判胜改进

Boss06 的对照说明“更早对空”“更快升龙”“更保守”都不必然更好。某些候选
改善开发开局，却在预留条件退步，因此没有采用。输入封装还可能意外改变
继承的距离阈值，导致名义上的单变量实验实际改了两项。

Vega07 发现计时首次归零后仍可能受击，立刻松开防守会把领先变成败局。
Sagat08 则从真实路线失败出发，对齐首次分岔，逐项检验跳入距离和扫腿保护。
这两轮把诊断从短促掉血记录扩展为受击前上下文、选招原因与完整轨迹。

同时出现过倒地姿势、时间平局和停表后 KO 的漏判。修复采用已核实的窄条件，
仍要求成熟结算与胜点；旧异常保留，修复后新开测试，不倒填历史胜利。

## 5. 最高难度与跨难度回归

原打法先冻结，再复制新分支训练最高难度。后来将高难度打法用于 Normal
及中间难度，暴露出 Blanka、Vega 等对手的新窗口与回归。

困难程度不是策略有效性的单调函数：最高难度训练通过，不能直接推出普通
难度也稳。Cross14 对远距出波、扫腿范围和低空等待作了局部调整，同时保留
未达到小局目标的事实。配置标签也不能代表游戏难度，必须检查原生 DIP。

## 6. 重置实验揭示重复轨迹，改用自然投币

软重置的多次通关出现相同逐局记录。随后硬重置实验也重现了相同轨迹，说明
当时的重开办法没有带来期待的样本多样性。它支持“该配置下轨迹重复”的
观察，不能据此确定游戏内部随机种子的具体值或普遍实现。

Coin17 改为让失败后的 continue 倒计时或结局自然结束，再重新投币选 Ken。
前七位对手顺序会变化，奖励关调度也改为按完成场数处理。新的自然路线
暴露出之前重复重置未覆盖的失败；自然投币从此成为正式验证方式。

## 7. 从最高五连到同一版本覆盖五档

Coin19 使用真实路线开局，对各对手做小幅调整、回归、冻结和自然投币验证，
最终完成最高难度五连。一个版本的失败触发回训后，旧版本封存，连胜重新
计数；训练成绩不能替代正式成绩。

跨难度目标随后要求同一套冻结策略覆盖 Normal 到最高难度。Coin22 的 V1、
V2、V3 均留下未完成该目标的记录：V2 未完成最高难度五连；V3 虽完成最高
五连，Normal 仍失败，剩余预算已不足以完成目标，因此提前退役。

V3 引入了 Bison 精确地面投技。V4 只进一步选入 Dhalsim 特定远距起攻时的
短蹲防，其他十位对手与 Core 保持 V3；同文件中注册的 Blanka 快 MP 候选
没有选入。最终 V4 在五档各完成五连，但累计仍有失败，不能称总体全胜。

## 8. 固定策略成为独立项目

最后保留 V4 的 fighter、Core 和 selection 原字节，重做跨平台安装、路径、
实例所有权、自然投币编排、CLI 和审计接口。旧本机训练工具没有整体搬入
发行版；本次加入的是可阅读、可复用的方法与历史总结。

未来的新优化应建立新实验版本，重新取得代表性开局并验证，不继承历史连胜。
平台移植的单元测试证明工具逻辑，实机烟测证明特定环境可运行，两者都不能
代替新的完整胜率实验。
