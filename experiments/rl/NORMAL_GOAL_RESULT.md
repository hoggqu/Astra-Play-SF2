# Normal 目标达成：完整 20 次，10 次通关

2026-09-12，固定的 Ken 神经策略完成一整批 **20 次自然投币，10 次通关、10 次失败、0 次无效运行**，本批通关率 **50%**，达到“20 次至少通关 10 次”的目标。正式环境为 macOS、MAME 0.288、Normal（难度值 3）；使用高速、静音、无窗口模式。

策略是一个启动前整体冻结的 `ppo_opponent_bundle`：11 个按对手 ID 固定路由的 PPO 分支，每个 actor 使用两层 64 单元 Tanh 网络。四个决策时刻组成 344 维观测，输出 pulsed16 动作，每 12 个原生帧决策一次。全部战斗动作由网络产生，没有 V4 战斗回退，也没有 Agent 在比赛内操作或调整策略。
