# 场景覆盖与 GPU 交叉对照

2026-09-14：独立审计后的短预算实验。此实验没有修改动作、奖励、模型结构或正式游玩的 argmax 选择方式。

## 预先固定的比较

两台机器分别完整执行 A 和 B，避免把方法与 GPU 后端完全混在一起。本机 MPS 先 A 后 B，远程 RTX 4090 CUDA 先 B 后 A。同一主机的 A/B 是主要比较，跨主机方向是否一致是补充证据；不是多随机种子的因果证明。

- 共同起点：上次远程 LR .0001 的最终完整 PPO ZIP（含 Adam 与对手采样状态），SHA256 `712576a12029860183f20e474013bd5e9eb00c19d1efabc15274accb9cd51001`。
- A：原场景池，每个对手 8 个训练开局。
- B：仅 Ryu、Blanka、Chun-Li，各保留隔一个选一个的 4 个旧开局，另外 4 个换为新自然采集开局；所有其他对手完全一致。总场景数保持 88。
- 新场景由已有独立训练采集器在 Normal 难度自然投币取得；先推进 137 个原生帧以改变启动相位，不读档、不重置、不写 RAM。采集使用冻结规则策略，因此不能声称直接补齐了 PPO 的那条精确 Ryu 失败轨迹。
- 训练场景不按本次胜负挑选。整个含 dev/holdout 样本的采集 attempt 都排除出新增训练候选；旧 dev/holdout 不进入训练。
- LR .0001、12 workers、全局 rollout 16384、mini-batch 256、4 epochs、每组 2 cycles×409600 decisions。两组都从共同起点重启训练，不从前一组继续。
- 新 managed 执行身份 v8，支持显式 MPS/CUDA，不可用时直接失败，不悄悄回退 CPU。MAME/Lua 采样依然在 CPU，GPU 负责 Torch 计算和更新。

## 验证

训练前在固定开发场景执行一次基线诊断。每个训练 cycle 之后自然投币 3 次；组结束后固定最终权重自然投币 20 次，再测同一开发场景。

开发诊断对所有 11 个对手各一个 dev 开局，lead 0/12，共 22 场；三个目标对手优先用新 dev 开局，其他对手使用既有 dev。诊断允许读档，仅衡量固定局面对战，不计为正式通关。holdout 不展开游玩。

报告分别列出冷启动首币、连续投币成绩、平均击败人数、失败对手、固定场景每小局和整场结果。不得合并不同权重的中间验证为最终通关率。自然投币序列不等于独立随机种子。

## 自动化

`python -m experiments.rl.scenario_dataset` 构建两组清单和共同开发清单。
`python -m experiments.rl.scenario_comparison --settings SETTINGS.json --output NEW_DIRECTORY` 执行每台主机上的两个实验组；settings 固定文件路径、hash、GPU、顺序、预算。中途错误会写 invalid 并停止该主机后续实验，不自动重试或改策略。

`comparison_monitor.py` 由本机 launchd 每 5 分钟运行一次，使用普通 Python 和 SSH 读取状态，不调用 AI。全部结束时只调用一次后台 Codex 生成结果分析并发桌面通知。进程退出或连续三次连接失败会通知异常；超过 12 小时则报告未完成状态，不自动杀死训练。

当前应用未提供可调用的定时任务工具，因此使用项目内脚本和 macOS 用户级 LaunchAgent；后台分析写入文件，并不声称可向当前对话注入新消息。

## 进入下一阶段的条件

先检查同一 GPU 内 B 相对 A 是否改善三个目标对手的固定场景结果、整条路线通关与首币回归，同时确认 Boss 能力没有明显倒退。两台方向一致时才值得扩大训练预算；方向矛盾时先增加重复实验，不同时修改奖励、网络或推理方式。随机训练与 argmax 部署的差异仍是待测假设，本实验不能单独回答它。

## 本机异常后的重启

本机首轮在 245760 次决策后的采样中遇到[零生命胜者结算异常](SETTLEMENT_V12.md)。
旧运行保留 invalid；最后完整 checkpoint 仅用于恢复能力的短测试。
修复后的本机 A/B 均从原共同初始模型重新开始，保持相同训练预算，使用
managed v9 / settlement v12。远程正在运行的 managed v8 / settlement v11 不被热更新。
比较时必须注明此版本差异：优先比较各主机内部相同版本的 A/B，不将跨主机结果差异
全部归因于 GPU 或场景采样，也不把本机失败运行中的采样计入新正式对照预算。
