# Sagat 采样权重 A/B

每台机器只运行一组：本机 A，远程 B；完成本组训练和验证后退出，没有交换组。
入口为 `python -m experiments.rl.sampling_comparison --settings SETTINGS.json --output NEW_RUN`。
settings 只接受单个 `arm: "A"` 或 `arm: "B"`，拒绝 `order`。

两组使用同一份完整 PPO checkpoint（上一轮本机 A 最终模型）、同一个原场景池，
Normal 难度，12 workers，GPU，学习率 0.0001，rollout 16384，mini-batch 256，4 epochs。
各训练 2×409600 次决策；每个 cycle 的 3 次自然币只作中间观察，最终权重固定后
各验证 40 次自然币。最终验证结束即退出。不根据中途成绩换模型或改参数。

A 保持现有自适应采样；B 在每次选择训练开局前，仅把 Sagat（角色 ID 9）的
自适应概率乘以 2，再将所有对手的概率归一化。若原 Sagat 概率为 p，实际新概率
为 2p/(1+p)，其他概率除以 (1+p)。这是相对抽样权重翻倍，不是实际概率直接翻倍，
更不保证得到两倍决策样本，因为每场持续时间不同。

原自适应历史、平滑和基础概率界限保留。倍率在其后应用，因此最终概率不再沿用
原 25% 上限：本次 B 的 Sagat 最高 40%，其他对手仍有正抽样概率。
模型中分别保存未加权的基础采样状态及倍率，续训不会反复叠乘。
每轮日志记录基础概率、倍率、最终概率、实际决策与小局数量。

通用训练入口也支持：

```sh
python -m experiments.rl.autotrain ... --opponent-multipliers '{"9":2}'
```

省略该参数时继承 checkpoint 的倍率；`--opponent-multipliers '{}'` 明确恢复无倍率。
旧 checkpoint 保留其原自适应状态，默认无倍率。
倍率仅影响下次训练整场开局抽样，不影响正在进行的对局、不修改动作或 PPO loss，
不改变自然投币验证路线。新 managed 身份 v10；两组均使用 settlement v12，
Lua、观测、动作、奖励和出招时序一致。

主要比较最终 40 币的通关次数、Sagat 导致的失败次数及其他对手是否退步。
硬件后端不同（MPS/CUDA），自然币序列也不是独立随机种子；结果只用于初步筛选。
不把训练胜率、中间模型验证或短测结果拼入最终通关率。

训练运行与定时监控均不需要 AI 实时参与。每 5 分钟由普通脚本读取一次状态，
平稳运行时保持安静，异常时发通知，两组结束后只调用一次结果分析并通知。
