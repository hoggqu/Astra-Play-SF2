# 首次神经网络 Normal 通关

2026-09-12，冻结的共享 PPO 模型用 Ken 在 Normal（difficulty 3）完成一次
11 对手通关。该批共 20 次自然投币：19 次有效失败，随后第 20 次通关，
没有无效尝试。每次失败后自然结束，再重新投币；成功的一次没有 continue、
重置、读档、存档或对手比赛中途暂停。

实际战斗由 Lua 执行冻结神经网络，每 12 个原生帧选择一次既有 16 动作宏。
网络使用四次决策时刻的历史观察组成 344 维输入，策略和价值分支各两层
64 单元 Tanh MLP。
同一套权重对付全部对手，没有 V4 战斗回退，也没有 Agent 逐招决策。
菜单、选人、奖励关和过场仍由固定流程处理。训练时允许加载训练开局；
训练成绩和本次无读档通关分开统计。

未完成对照预算，尚不能比较收益。原模型、原执行包与新的候选保持不同身份。

## 检查与复现边界

该批全部 102 场对手比赛的审计通过，共检查 572209 个原生帧、36260 次决策。
独立复核再次检查原包身份、模型重新导出的字节、21 个包文件、20 个运行文件、
1278 个封存文件哈希以及原生帧时序。成功尝试的 11 个不同对手、逐小局比分、
原生胜场标记和生命周期一致，没有重置、读写存档或场内暂停违规。

模型、精确的旧部署包、成功尝试记录、结局截图与校验清单已在本地封存。
仓库保留方法和结果摘要，不包含 ROM、模型权重或原始逐帧历史。获得原部署
包和模型后，配置 MAME／兼容 ROM，可用以下方式独立运行，无需 AI Agent：

```sh
python ORIGINAL_CODE/launch.py native_continuous --model MODEL.zip --output NEW_OUTPUT --difficulty 3 --attempts 20 --speed fast
```

输出目录必须全新。复现该实验应使用上述原包身份，不能悄悄替换为更新的
结算或训练时序版本。软件的跨平台支持不等于本次轨迹已在所有平台重复验证。

这批样本的通关比例是 1/20，即 5%，尚不足以说明稳定胜率。它也不是整个
研究过程所有模型和尝试的总通关比例；不同运行可能重现启动序列，不应把
重复序列宣称为独立样本。第一步“一次无 continue 的 Normal 通关”已达成，
后续若继续训练，应以这份冻结模型为基线，再验证可靠性是否提高。
